✅ Wiring Checklist

  • 1️⃣ Arduino GND → Row 13A (bottom rail)
  • 2️⃣ Pin 8 → Row 13E → LED1+ (Row13J); LED1− (Row15J) → R1 (15D→13D)
  • 3️⃣ Pin 9 → Row 20E → LED2+ (Row20J); LED2− (Row22J) → R2 (22D→13H)
  • 4️⃣ Pin 13 → Row 27E → LED3+ (Row27J); LED3− (Row29J) → R3 (29D→13J)
  • 5️⃣ All resistors connect back to shared GND rail
💡 Circuit Rule: Current flows: Pin → LED → Resistor → GND. Always!
